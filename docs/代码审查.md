### 安全与架构核对

- 业务写路径遵循 `API → Service → Repository → Model/DB`，Router 未直接操作 ORM。
- 所有 `/api/v1` 请求仍受 runtime secret 保护；认证入口外的阶段 4 API 同时校验 JWT，admin 路由额外校验角色。
- JWT 强制 `sub`、`role`、`ver`、`iat`、`exp`、`jti`；用户禁用、角色变化、改密或密码重置会使旧 Token 失效。
- Token 由 Electron Main 使用 safeStorage 加密持久化；renderer 仅内存持有，未使用 `localStorage`/`sessionStorage`，safeStorage 不可用时无明文回退。
- 管理接口只返回账号元数据，不包含密码哈希、`token_version` 或他人报告正文；敏感模式扫描未发现凭据日志。
- JWT 签名密钥为数据目录首次启动随机生成的 256-bit 值，独占创建、重启复用、损坏拒绝使用，未硬编码或暴露给 renderer。
